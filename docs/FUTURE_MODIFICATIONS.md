# Future modifications after the complete CodeBreak Tower

These modifications are **post-v1 roadmap ideas**, not included in this release:

1. **Persistent full-stack workspace**: per-player files, real Node/Express execution in isolated locked-down containers, real PostgreSQL query grading with ephemeral disposable databases, strict resource isolation, auditing and abuse controls.
2. **Advanced curriculum**: TypeScript, testing-driven development, React, accessibility engineering, CI/CD, Docker, OAuth/OIDC, caching, WebSockets, real project deployment, threat modeling.
3. **Accessibility**: optional no-physics lesson mode, screen-reader-friendly non-canvas equivalent, customizable key bindings, reduced motion, color-contrast and dyslexia-friendly settings.
4. **Character animations**: procedural hand/feet IK, expressive face variants, richer environmental storytelling, cutscenes and sound effects.
5. **Original narrative chapters**: NULL origin side missions, PATCH backstory, branching ending choices and collectible Architect logs.
6. **Offline-first/mobile**: local installable PWA, compact performance mode for entry-level phones, optional Android/desktop packaging.
7. **Teacher and learner dashboard**: role-based analytics, class creation, teacher-authored challenges, mastery reviews (privacy-first).
8. **Multiplayer pair programming**: collaborative puzzles, peer reviews and shareable project demos with moderation and strong safety measures.
9. **Learning science**: spaced recall, adaptive hints, mastery validation with unseen tasks, revision recommendations.
10. **Production operations**: observability, account migration, export portability, robust error reporting and continuous QA.

Even if the game is narratively complete at Floor 100, practical mastery requires independently creating a real application and using the real capstone. Future curriculum should assess that work rather than infer competence from simulated code puzzles alone.
